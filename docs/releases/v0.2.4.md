The Read button's shortcut now works with one hand. Unmuddle is a set of free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## What's changed

- **Ctrl+Alt+D shows the Read button.** It was Ctrl+Alt+J, which took two hands while one was on the mouse. Ctrl, Alt and D all sit under the left hand. If your copy is still on Ctrl+Alt+J it moves across by itself and tells you once. If you already use Ctrl+Alt+D for something else, nothing changes.
- **Every shortcut is yours to choose.** Go to Settings, then Read button. Click a shortcut's box and press the keys you want. That goes for showing the Read button, reading a selection (Ctrl+Alt+H) and opening Compose (Ctrl+Alt+C).

Word uses Ctrl+Alt+D to insert an endnote. If you need that, give the Read button different keys.

## Install

- **`Unmuddle-0.2.4-setup.exe`** installs for your user only. No admin rights needed. It replaces the version you have and keeps your settings.
- **`Unmuddle-0.2.4-win-x64.zip`** runs from any folder. Unzip it and run `Unmuddle.exe`.

**Already have Unmuddle?** If you switched the update check on, it offers this version by itself. Otherwise go to Settings, then Updates, and press **Check now**. Then **Update now**. In 0.2.2 and earlier, Check now is under Settings, then Privacy and licences.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Want to check a download?** Each file has a record, signed by GitHub, that it was built from this project's code by its own release workflow. They're listed on the [attestations page](https://github.com/drhumphrey/unmuddle/attestations). With the GitHub CLI you can check a file yourself: `gh attestation verify Unmuddle-0.2.4-setup.exe --repo drhumphrey/unmuddle`.

This is an early version. [docs/STATUS.md](https://github.com/drhumphrey/unmuddle/blob/main/docs/STATUS.md) lists what's been tried and what hasn't. Problems and ideas are very welcome as [issues](https://github.com/drhumphrey/unmuddle/issues).
