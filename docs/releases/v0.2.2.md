The Read button now waits until you ask for it. Unmuddle is a set of free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## What's changed

- **The Read button no longer pops up after every selection.** Most selections are made to copy something, or are part of work in a design app, and a button beside each one gets in the way. Now nothing appears until you ask.
- **Ctrl+Alt+J shows the button.** Select some text, press Ctrl+Alt+J, and the button appears at your mouse with Read, Edit and Paste.
- **Ctrl+Alt+H still reads a selection straight away,** with no button.
- **Prefer the old way?** Go to Settings, then Read button, and switch on **Show after every selection**. You can change the new shortcut on the same page.

The first time this version starts, a message tells you about the change.

## Install

- **`Unmuddle-0.2.2-setup.exe`** installs for your user only. No admin rights needed. It replaces the version you have and keeps your settings.
- **`Unmuddle-0.2.2-win-x64.zip`** runs from any folder. Unzip it and run `Unmuddle.exe`.

**Already have Unmuddle?** If you switched the update check on, it offers this version by itself. Otherwise go to Settings, then Privacy and licences, and press **Check now**. Then **Update now**.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Want to check a download?** Each file has a record, signed by GitHub, that it was built from this project's code by its own release workflow. They're listed on the [attestations page](https://github.com/drhumphrey/unmuddle/attestations). With the GitHub CLI you can check a file yourself: `gh attestation verify Unmuddle-0.2.2-setup.exe --repo drhumphrey/unmuddle`.
