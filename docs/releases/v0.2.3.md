Updates has its own page in Settings. Unmuddle is a set of free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## What's changed

- **A page for updates.** Settings now has an **Updates** page: the version you have, **Check now**, and the switch for checking once a day. It used to sit on the Privacy and licences page, which wasn't where anyone looked for it.

Also new since 0.2.1, if you're coming from there:

- **The Read button waits until you ask.** It no longer pops up after every selection. Select some text and press **Ctrl+Alt+J**, and it appears at your mouse with Read, Edit and Paste. **Ctrl+Alt+H** still reads a selection straight away. To have the button appear by itself again, go to Settings, then Read button, and switch on **Show after every selection**.

## Install

- **`Unmuddle-0.2.3-setup.exe`** installs for your user only. No admin rights needed. It replaces the version you have and keeps your settings.
- **`Unmuddle-0.2.3-win-x64.zip`** runs from any folder. Unzip it and run `Unmuddle.exe`.

**Already have Unmuddle?** If you switched the update check on, it offers this version by itself. Otherwise press **Check now**, then **Update now**. In this version Check now is under Settings, then Updates. In 0.2.2 and earlier it's under Settings, then Privacy and licences.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Want to check a download?** Each file has a record, signed by GitHub, that it was built from this project's code by its own release workflow. They're listed on the [attestations page](https://github.com/drhumphrey/unmuddle/attestations). With the GitHub CLI you can check a file yourself: `gh attestation verify Unmuddle-0.2.3-setup.exe --repo drhumphrey/unmuddle`.

This is an early version. [docs/STATUS.md](https://github.com/drhumphrey/unmuddle/blob/main/docs/STATUS.md) lists what's been tried and what hasn't. Problems and ideas are very welcome as [issues](https://github.com/drhumphrey/unmuddle/issues).
