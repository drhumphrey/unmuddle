Three fixes from daily use. Unmuddle is a set of free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## What's changed

- **Only one copy runs at a time.** Starting Unmuddle again used to start a second copy, and the two fought over the shortcuts. Now a message tells you it's already running, by the clock.
- **A new shortcut for reading: Ctrl+Alt+H.** The old one, Ctrl+Alt+Space, is used by other apps too. If yours is still Ctrl+Alt+Space and another app has it, Unmuddle moves to Ctrl+Alt+H by itself and tells you once. A shortcut you chose yourself is never changed. You can pick your own in Settings, on the Read button page.
- **The Read button stays out of the way.** It no longer appears when you open a file with a double-click, drag a file, or drag a box around several. It now appears only when the mouse pointer was the text pointer, the thin upright bar. If an app never shows the button, select the text and use the shortcut.

## Install

- **`Unmuddle-0.2.1-setup.exe`** installs for your user only. No admin rights needed. It replaces the version you have and keeps your settings.
- **`Unmuddle-0.2.1-win-x64.zip`** runs from any folder. Unzip it and run `Unmuddle.exe`.

**Already have 0.2.0?** If you switched the update check on, Unmuddle offers this version by itself. Otherwise go to Settings, then Privacy and licences, and press **Check now**. Then **Update now**.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Want to check a download?** Each file has a record, signed by GitHub, that it was built from this project's code by its own release workflow. They're listed on the [attestations page](https://github.com/drhumphrey/unmuddle/attestations). With the GitHub CLI you can check a file yourself: `gh attestation verify Unmuddle-0.2.1-setup.exe --repo drhumphrey/unmuddle`.

This is an early version. [docs/STATUS.md](https://github.com/drhumphrey/unmuddle/blob/main/docs/STATUS.md) lists what's been tried and what hasn't. Problems and ideas are very welcome as [issues](https://github.com/drhumphrey/unmuddle/issues).
