Closing the player stops the voice, and you can see when Unmuddle is reading. Unmuddle is a set of free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## What's changed

- **Closing the player stops the voice.** The cross on the player used to hide it and leave the voice talking, with nothing on screen to stop it. Now it stops the reading, then closes. **Show player** in the Unmuddle menu brings it back.
- **A play mark while reading.** While the voice is reading, the Unmuddle icon by the clock shows a small play mark. The Unmuddle menu shows the same mark beside **Pause / Resume** and **Stop**.

## Install

- **`Unmuddle-0.2.5-setup.exe`** installs for your user only. No admin rights needed. It replaces the version you have and keeps your settings.
- **`Unmuddle-0.2.5-win-x64.zip`** runs from any folder. Unzip it and run `Unmuddle.exe`.

**Already have Unmuddle?** If you switched the update check on, it offers this version by itself. Otherwise go to Settings, then Updates, and press **Check now**. Then **Update now**. In 0.2.2 and earlier, Check now is under Settings, then Privacy and licences.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Want to check a download?** Each file has a record, signed by GitHub, that it was built from this project's code by its own release workflow. They're listed on the [attestations page](https://github.com/drhumphrey/unmuddle/attestations). With the GitHub CLI you can check a file yourself: `gh attestation verify Unmuddle-0.2.5-setup.exe --repo drhumphrey/unmuddle`.
